# Cisco-Secure-Access-Switch
Segmentation and routing: staff, guest and management VLANs, with the switch routing between them and running DHCP itself. Layer 2 security: port security, BPDU guard, DHCP snooping, ARP inspection and storm control. Guest isolation: an ACL that keeps guests away from the internal networks. Management: SSH only, restricted by ACL, plus the console.
