# Evidence

Screenshots and captured outputs from the physical lab.

| Folder | Contents |
|--------|----------|
| `screenshots/` | One screenshot per test ID in [the test plan](../docs/04-test-plan.md) (e.g. `T04-pca-ipconfig.png`) |

Capture guidelines:

- Take screenshots from the real device, not from examples.
- Crop out personal information, serial numbers and any real passwords.
- Use PNG, keep file names identical to the test plan.
